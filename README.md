## 📐 Essential Typography Metrics

When designing a [**custom font**](https://customfontmaker.com/) with FontQuill:

- **Baseline**: The invisible line upon which all letters sit.
- **X-Height**: The vertical height of lowercase letters such as `x`, `a`, and `e`.
- **Cap-Height**: The height of capital letters from the baseline.
- **Ascender & Descender**: Portions of characters that extend above the cap-height (like `b`, `d`, `h`) or below the baseline (like `g`, `p`, `y`).
- **Kerning**: Adjusting the optical spacing between specific letter pairs (e.g. `AV`, `To`, `Wa`).

## 🎨 Best Practices for Handwriting Fonts

1. **Consistent Stroke Weight**: Use an even-nib rollerball or calligraphy pen when filling the template.
2. **Standard Alignment**: Ensure all characters touch the baseline without floating or sinking.
3. **Punctuation Balance**: Match the optical size of quotation marks, apostrophes, and commas to lowercase letters.
